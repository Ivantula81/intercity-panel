# Дизайн: профессионализация репозитория панели

**Дата:** 2026-06-14
**Статус:** утверждён, в работе

## Цель
Привести проект панели к виду, в котором его легко понять и поддерживать другим людям:
версионирование (git), бэкап, README и история версий, базовое ревью безопасности.

## Контекст и ограничения
- Рабочая папка-родитель — слепок домашней директории сервера: содержит `.ssh/`, `.bash_history`
  (с паролем root), CSV с персональными данными пассажиров. **Версионировать её нельзя.**
- Реальный проект — каталог `panel/` (деплоится в `/var/www/panel`).
- Секреты панели — в `/etc/panel.env` (в коде не хранятся), читаются через `env_get()`.

## Решение
1. **Git только для `panel/`** — отдельный чистый репозиторий. В родительскую папку кладём
   защитный `.gitignore` (игнор всего), чтобы случайный `git add .` не утащил секреты/PII.
2. **Безопасность до первого коммита**: вынести захардкоженные секреты из кода —
   - GDS логин/пароль (`lib/gds/incGds.php`) → `GDS_LOGIN`/`GDS_PASSWORD` в env;
   - аварийный админ-пароль (`app/bootstrap.php`) → `ADMIN_FALLBACK_PASSWORD` (по умолчанию выключен).
   Чтение пароля устойчиво к контексту (env → `env_get()` → прямое чтение `/etc/panel.env`),
   т.к. GDS вызывается и из cron, где `api.php` не подключён.
3. **`.gitignore` panel/**: исключить `public/uploads/`, `*.log`, локальные `.env`, OS-мусор.
4. **README.md** — назначение, стек, архитектура (роутер `?p=`, API `?p=api&a=`, каналы,
   webhooks, Gotenberg), структура, конфиг `/etc/panel.env`, развёртывание и деплой.
5. **CHANGELOG.md** — история версий (Keep a Changelog), релиз `1.0.0` + история схем `schema..10`.
6. **Первый коммит** чистого состояния.
7. **Бэкап** — приватный репозиторий на GitHub (`ivantula81`), пуш. История версий = git-история.
8. **Ревью** кода (Superpowers `requesting-code-review`); первая находка — захардкоженные секреты,
   закрыта в п.2.

## Проверка
- `php -l` изменённых файлов; на сервере — отсутствие хардкода `77Ivan77`, резолв пароля из env.
- Поведение GDS не меняется (значение пароля идентично, источник — env).
