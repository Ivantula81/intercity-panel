# Демонстрация интерфейса · версия 2

23.09.2026. Эскиз для визуального сравнения, на искусственных данных.

[Исходник](prototypes/workspace-v2.html) содержит самостоятельный HTML-фрагмент.
Он не подключён к рабочему приложению и не вызывает его API.

## Что можно посмотреть

- Главный экран с примерами переходов.
- Список с поиском и фильтром.
- Карточку с тремя вкладками и пробной заметкой.
- Два условных диалога с независимыми черновиками и предпросмотром.
- Пример представления условных сумм и двух отдельных состояний.

Можно переключать Inter, Golos Text и системный шрифт, а также две плотности.
Для переключателей используется необязательный механизм среды просмотра;
без него остаётся стандартное оформление.

## Сохранение примера

При доступном браузерном хранилище пробный контекст сохраняется на устройстве.
Окно восстановления — 24 часа после последнего сохранения. Если хранилище
недоступно, интерфейс сообщает об этом и работает в памяти открытого примера.
Использовать только вымышленные данные.

Пример не моделирует сервер, вход, совместное редактирование или доставку
сообщений. Восстановление прокрутки и история браузера не реализованы.
Все суммы и записи созданы специально для демонстрации.

## Проверки этого изменения

Проверены синтаксис JavaScript, уникальность HTML-идентификаторов, наличие
пяти экранов и отсутствие вызовов API. Полная визуальная и поведенческая
приёмка не выполнялась. Изменение не является выпуском приложения.
