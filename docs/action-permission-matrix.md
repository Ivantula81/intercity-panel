# Матрица действий и журнал сотрудников

Документ фиксирует серверные границы до внедрения отдельных ролей. Проверка
должна находиться в API/контроллере, а не только в интерфейсе.

| Область | Действия | Оператор | Администратор | Событие журнала |
|---|---|---:|---:|---|
| Ведомость | просмотр, правка пассажира, явка, возврат, добавление | да | да | `manifest.passenger.*` |
| Расчёт | предварительный расчёт, снимок, наличные | да | да | `reporting.calculate`, `reporting.snapshot`, `reporting.cash.*` |
| Справочники | агенты, станции, автобусы, водители | по политике владельца | да | `catalog.*` |
| Рассылки | просмотр групп/каналов, подготовка | да | да | `campaign.view`, `campaign.prepare` |
| Рассылки | запуск, повтор, удаление задания | нет по умолчанию | да | `campaign.send`, `campaign.retry`, `campaign.delete` |
| Чаты | чтение, назначение, статусы, заметки | да | да | `chat.*` |
| Контакты | изменение карточки | да | да | `contact.update` |
| Экспорт/файлы | отчёты и документы | да | да | `export.*`, `file.*` |
| Настройки каналов | аккаунты, webhook, SMTP, лимиты | нет | да | `settings.channel.*` |
| Пользователи | создание, роль, активация, удаление | нет | да | `user.*` |

На первом шаге журналирует только действие, раздел, сущность, результат и
технический контекст. Пароли, токены, телефоны, email, текст сообщений и
полные payload запрещены. Просмотры страниц не журналируются, чтобы метрики
показывали использование функций, а не шум навигации.
