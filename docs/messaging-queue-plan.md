# Устойчивая очередь рассылок

`broadcast_jobs` — одно задание кампании с неизменяемым payload и
идемпотентным ключом. `broadcast_deliveries` — отдельная строка на получателя и
канал. Повтор HTTP-запроса не создаёт второе задание, а timeout провайдера не
стирает состояние попытки.

Worker должен брать только `queued`/просроченные `running` строки, атомарно
ставить блокировку, отправлять одну delivery и сохранять `accepted/failed`.
Webhook переводит `accepted` в `delivered/read`. Повтор разрешён только по
политике backoff и ограниченному числу попыток. Реальные массовые отправки до
smoke-теста на согласованном тестовом номере запрещены.
