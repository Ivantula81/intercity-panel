## Что восстанавливается

| Область | Сохраняемый контекст | Граница |
| --- | --- | --- |
| Ведомости, контакты, отчётность | Последняя страница раздела, открытый объект, параметры URL, позиция страницы | Несохранённые поля не становятся сохранёнными; сохраняется предупреждение об уходе |
| Продажи | Поддерживаемые URL-фильтры и позиция страницы | Только параметры из явного списка; произвольный URL не сохраняется |
| Уведомления | Открытая ведомость из URL и позиция страницы | Внутренние вкладки, AJAX-фильтры, выбор получателей и черновики рассылок пока не восстанавливаются |
| Чаты | Очередь, канал, поиск, диалог, отдельные черновики, положение списка и текущего окна истории | Восстанавливается загруженное окно истории, а не весь архив сообщений |
| Возврат через меню | Последнее место внутри выбранного раздела | Явные ссылки и ссылка сброса фильтров имеют приоритет |
| Повторное открытие корня приложения | Последняя подтверждённая копия рабочего места | Корневой адрес без перехода из интерфейса, то же устройство и действующий вход |

Back/Forward в чатах меняет выбранный диалог. Прямой ID может открывать
диалог за пределами первой страницы списка. Старый ответ не переключает
текущий диалог. До успешного ответа API о текущем диалоге редактор закрыт,
а сохранённый текст не показывается. Недоступная ведомость/карточка/отчёт
имеет путь возврата к списку. Восстановление не выполняет отправку.

Настройки, журналы, произвольные формы, пароли, финансовые изменения,
шаблоны рассылок и внутренние заметки не копируются. Эта карта является
границей этапа, а не заявлением о восстановлении всех экранов приложения.

## Хранение и изоляция

Используется AES-GCM через Web Crypto, случайный IV для каждой записи и
ключ текущего входа. Ключ хранится в серверной сессии и передаётся только
авторизованной странице; в Web Storage он не записывается. Ответ страницы
помечен `private, no-store`. Каждый успешный вход создаёт новый ключ;
выход уничтожает серверную сессию и очищает копию браузера.

Зашифрованная копия `sessionStorage` принадлежит вкладке. Обычные записи
другой вкладки не заменяют её содержимое. `localStorage` содержит последнюю
копию для нового открытия; это не объединение нескольких одновременно
редактируемых рабочих мест. Две вкладки одного диалога имеют независимые
копии текста. Ключ входа и очищение не являются механизмом серверных прав.

Срок восстановления — семь дней после последнего сохранения контекста,
не дольше жизни входа и хранения браузера. Новый вход изолирует старые копии,
в том числе в других открытых вкладках. Возврат из browser back/forward cache
перезагружает страницу для штатной проверки входа сервером.

Копия ограничена 512 КиБ. При недоступности Web Crypto, запрете/переполнении
хранилища или ошибке записи показывается предупреждение, введённый текст
остаётся на экране, предупреждение об уходе сохраняется. Просроченная,
повреждённая или неподходящая копия не восстанавливается. Шифрование копии
не защищает от вредоносного кода, уже выполняющегося в авторизованной странице.

Запись происходит после изменений с небольшой задержкой и перед обычной
навигацией. Принудительное завершение процесса до завершения записи может
потерять самый последний ввод. Незавершённая отправка всегда оставляет
предупреждение об уходе; восстановленный неопределённый результат предлагает
сначала проверить историю и никогда не отправляет сообщение сам.

Справочные основания: [MDN — Web Crypto AES-GCM](https://developer.mozilla.org/en-US/docs/Web/API/SubtleCrypto/encrypt),
[MDN — sessionStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/sessionStorage).

## Проверки и воспроизведение

```sh
./scripts/preflight.sh
node tests/workspace_ui_test.cjs
node tests/save_draft_ui_test.cjs
```

Нужны PHP с PDO SQLite, Node, Playwright и Chromium/Chrome. Для отдельного
браузера использовать `CHROME_PATH`, для внешней установки модулей —
`NODE_PATH`. `WORKSPACE_SCREENSHOT_DIR` сохраняет мобильный снимок.

Браузерный сценарий использует настоящий layout, представления и JS/CSS,
CLI-фикстуру с вымышленным пользователем и ключом, полностью подменённый API.
Профиль и локальный сервер временные. Для проверки перезапуска закрывается
весь процесс браузера и снова открывается тот же временный профиль.
Вызовы внешних адресов запрещены, рабочая БД и сообщения не используются.

Итог: 16 групп восстановления и 15 групп регрессии успешны, ошибок JavaScript
нет; штатный preflight успешен. Итоговый список: [workspace-restore-result.json](workspace-restore-result.json).
Регрессия предыдущего этапа: [workspace-restore-regression.json](workspace-restore-regression.json).
PHP-проверка ключа включена в preflight. Она проверяет отсутствие ключа без
входа, стабильность внутри входа, разделение пользователей и ротацию после
сброса. Реальный вход с рабочей БД и серверная доставка не тестировались.
