# Рабочий сценарий ведомости — 25.10.2026

Основание: согласованный концепт #37, журнал #35 LOG-093/094.

## Изменение

Существующий раздел ведомостей получает поиск по маршруту/номеру во всей базе,
даты отправления, фильтр незаполненных времени/автобуса/телефона водителя,
страницы по 30 строк и явный охват. Каждая строка остаётся отдельной ведомостью
по внутреннему ID. Это не реестр всех рейсов ГДС, номера не объединяются.
«Основные поля заполнены» не означает проверенную готовность рейса.

Карточка содержит разделы подготовки, пассажиров и явно связанных диалогов.
Существующие сохранение, импорт, документы, уведомления и отправка не заменены.
Ошибка сохранения видна независимо от вкладки. Вкладки разделены по ID объекта
в существующем зашифрованном рабочем контексте; явная вкладка URL имеет приоритет.
Возврат к списку использует отдельный сохранённый URL поиска/страницы, а не
последнюю открытую карточку. Смена вкладок поддерживает Back/Forward и клавиатуру.

Диалоги выбираются только по conversations.manifest_id. Переход к переписке
передаёт числовой return_manifest: это происхождение перехода, не новая связь
диалога. Переключение диалога сохраняет ссылку возврата; сервер по-прежнему
проверяет доступ к открываемому объекту. Пустой список не выдаётся за отсутствие
всех сообщений пассажиров или за доставку уведомлений.

## Проверки

- Полный scripts/preflight.sh, включая 17 утверждений нового read-only списка.
- Поиск старых записей, буквальные %/_/!, SQL-подобная строка, даты, страницы,
  непригодные параметры, одинаковые внешние номера, число пассажиров, явные
  связи диалогов и отказ БД без ложного пустого результата.
- 12 групп нового браузерного сценария на реальных PHP-представлениях и
  контроллере списка с синтетической SQLite: список → карточка → диалог →
  возврат, черновик, два объекта/вкладки браузера, прямые ссылки, Back/Forward,
  отказ сохранения с сохранением ввода, пустая выборка и недоступный объект.
- 1360/390/320 px, клавиатура, reduced motion, 200% увеличение карточки;
  последние поля доступны прокруткой, таблица пассажиров не расширяет страницу,
  редактор переписки с возвратом остаётся над нижней навигацией. Снимки просмотрены.
- Регрессия: 17 групп workspace_ui_test.cjs, 15 групп save_draft_ui_test.cjs.
- Ошибок JavaScript в выполненных сценариях нет. Внешние запросы запрещены
  тестовой обёрткой. Настоящие сообщения и рабочие записи не использованы.

Команды: scripts/preflight.sh; node tests/trip_workspace_ui_test.cjs;
node tests/workspace_ui_test.cjs; node tests/save_draft_ui_test.cjs.
Браузерным проверкам нужны Playwright, Chrome и PHP с PDO SQLite.
CHROME_PATH и NODE_PATH позволяют использовать внешнюю установку.
TRIP_SCREENSHOT_DIR сохраняет синтетические снимки.
