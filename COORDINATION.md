# Координация агентов (Claude + Codex)

Над панелью работают два ИИ-агента. Эти правила — чтобы не толкаться в одних файлах и видеть работу друг друга через GitHub.

## Где кто работает
| | Каталог (worktree) | Ветка |
|---|---|---|
| **Claude** | `/root/panel-claude` | `claude/<задача>` |
| **Codex** | `/root/panel-codex` | `codex/<задача>` |
| деплой/интеграция | `/root/panel-src` | `main` — тут НЕ работают руками |

Worktrees делят одну git-историю, но у каждого свой каталог и ветка — файлы друг друга не перезаписываются.

## Правила
1. **Перед началом:** `git fetch --all && git log --all --oneline` — увидеть, что сделал другой.
2. Коммить часто; каждый коммит **авто-пушится** на GitHub (хук `post-commit`).
3. Правишь только файлы **своей зоны** (см. ниже). Общие файлы — согласовать в журнале.
4. Перед коммитом — **lint**: `php -l <файл>`, `node --check public/assets/panel.js`.
5. Готовый и проверенный кусок → **PR** (`gh pr create`) → merge в `main` → деплой `/root/deploy.sh`.
6. **Живой сайт — только из `main`.** WIP-ветки на прод не льём.
7. Меняешь дизайн/логику — **сначала макет/план, потом код** (требование владельца).
