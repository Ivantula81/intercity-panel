## [1.0.0] — 2026-06-14
Первый версионированный релиз: проект переведён под git, добавлены README и история версий,
секреты вынесены из кода в окружение.

### Security
- Логин и пароль GDS вынесены из `lib/gds/incGds.php` в `/etc/panel.env` (`GDS_LOGIN`, `GDS_PASSWORD`).
- Убран захардкоженный аварийный админ-пароль в `app/bootstrap.php` — теперь только из `ADMIN_FALLBACK_PASSWORD`, по умолчанию выключен.

### Added — возможности на момент релиза
- Уведомления пассажирам по каналам: WhatsApp (Evolution API, Green API), MAX/Telegram (Green API), e-mail (SMTP smtp.bz).
- Ведомости из CSV (Jasper): распознавание рейса и пассажиров, редактор пассажиров, печать.
- Справочники (остановки/автобусы/водители/шаблоны), группировка по станции посадки, времена из GDS.
- Переменные сообщений с нестрогой подстановкой + справочник своих переменных.
- Свободная рассылка по списку номеров (с картинкой).
- Документы водителю и дорожные: PDF (Gotenberg) / Word / печать, печать и подпись, договоры-фрахтователи.
- CRM: авто-сбор контактов из всех отправок, страница контактов, экспорт CSV.
- Сотрудники: логин/роли, учёт авторства отправок.
- Webhooks Evolution и Green API: статусы доставки/прочтения, входящие сообщения.
- Выбор провайдера канала (Evolution / Green API), мультиаккаунт WhatsApp.
- Чаты: диалоги по контактам, лента входящих+исходящих, ответ через активный канал.
- Вложения во входящих: скачивание и кэш медиа, показ картинок/файлов в чате.
- Полный редизайн UI + мобильная версия.
- Мониторинг занятости рейсов из GDS (cron) + дашборд.

### Migrations (история схем БД)
- `schema.sql` — базовые таблицы: ведомости, пассажиры, сообщения, ссылки.
- `schema2` — справочники: остановки, автобусы, водители, шаблоны, группы ведомостей.
- `schema3` — контакты (CRM), кэш расписаний рейсов.
- `schema4` — пользовательские переменные сообщений.
- `schema5` — пользователи (сотрудники) и аккаунты WhatsApp.
- `schema6` — статусы доставки/прочтения (`wa_id`/`delivered_at`/`read_at`), входящие (`inbox`), ID станций.
- `schema7` — перевозчики, журнал документов, поля пассажира (цена/гражданство/комментарий/ДР).
- `schema8` — провайдер у аккаунта канала (`wa_accounts.provider`).
- `schema9` — отметка прочтения входящих (`inbox.is_read`) для чатов.
- `schema10` — вложения во входящих (`inbox.media_url`/`media_type`).
